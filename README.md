# Calculator

A simple interactive calculator application built using HTML, CSS, and JavaScript.

This project was completed as part of The Odin Project curriculum and demonstrates fundamental programming concepts such as event handling, state management, DOM manipulation, and modular arithmetic logic.

[Live Preview](https://austinej101.github.io/Calculator/)
## Features

- Perform basic arithmetic operations:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)
  - Remainder (%)

- Chain multiple operations
- Delete last entered digit
- Clear entire calculator state
- Dynamic expression and result display

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM API

## Concepts Practiced

- Event handling and event delegation
- Application state management
- DOM manipulation and updates
- Separation of concerns
- Input validation and control flow
